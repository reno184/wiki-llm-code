# Recherche mission ESN : nouveaux filtres de candidature

Usage: à ressortir dès qu'un CV doit être envoyé (mission freelance via ESN, TJM ~470 €). Le mode de tri des candidats a changé : comprendre et appliquer le nouveau filtrage des candidats/CV.

## Le principe

**Les compétences seules ne suffisent plus** : les filtres automatiques scannent les mots-clés **mission par mission**. Il faut donc **répéter les mots-clés pertinents sur chaque mission** du CV.

- Résultat : le CV « ne ressemble à rien » visuellement, **mais passe les filtres** — c'est le but recherché.
- Compétences globales = nécessaires mais non suffisantes ; la répétition par mission est ce qui déclenche le match.

## Exemple de référence

- **Le CV utilisé pour l'entretien CEPAC** : reformaté par **Mooeh avec une IA** — on y voit les techniques de mots-clés répétés pour chaque mission. S'en servir de modèle.
- Où le trouver : fichier **CV_CEPAC** dans le Finder, ou le **mail de Loïc Toussain** envoyé dans ma **boîte mail iCloud** (pas Gmail).

## À faire avant la prochaine candidature

- Reprendre le CV_CEPAC comme template de structure (mots-clés répétés par mission).
- Reformater le CV de mission via la même approche avant chaque envoi ESN.
